プロジェクト nishiki-recycle の設定はすでにこのページに埋め込まれています。開いた全員の端末が自動で同じ地図に接続し、フラグはリアルタイムで同期されます。下の欄は、別のプロジェクトに切り替えたいときだけ使ってください。

  1. Firestoreの「ルール」タブに、下のルールが公開されていることを確認してください。
  2. 別のプロジェクトに切り替える場合は、その firebaseConfig を下の欄に貼って「Firebaseに接続する」を押してください。
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /nishiki_flags/{doc} {
      allow read, write: if true;
    }
    match /nishiki_meta/{doc} {
      allow read, write: if true;
    }
  }
}
